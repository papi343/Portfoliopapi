# Portfolio — Yaya Dabo | Développeur Backend & Full-Stack

Portfolio professionnel de **Yaya Dabo**, étudiant en Génie Logiciel (Licence 3, ISI Keur Massar, Dakar) et développeur full-stack freelance depuis 2024.

## Positionnement & Spécialités

- **Backend & Conception d'API REST** : PHP / Laravel, Node.js / NestJS, Authentification JWT / Sanctum, Gestion des rôles (RBAC, Guards, Policies), Architecture modulaire & principes DDD, WebSockets (`Socket.IO`), Paiements Stripe (Webhooks signés).
- **Bases de données & ORM** : MySQL, PostgreSQL, Redis, Modélisation relationnelle (UML, Merise MCD/MLD), Transactions SQL, Prisma ORM, Eloquent ORM.
- **Frontend & Mobile** : JavaScript (ES6+), TypeScript, React.js, Next.js, Tailwind CSS, React Native (en cours d'apprentissage).

## Stack du Portfolio

- **Framework** : Next.js 14 (App Router)
- **Langage** : TypeScript 5
- **Style** : Tailwind CSS 3 & Lucide Icons
- **Polices** : Plus Jakarta Sans, DM Sans & Space Mono

## Pages principales

- `/` — **Accueil** : Présentation du profil, objectifs de stage/poste junior, piliers techniques et aperçu des projets phares.
- `/about` — **À propos** : Parcours, méthodologie de travail, expériences freelance/communautaires et formations académiques.
- `/skills` — **Compétences** : Compétences organisées par catégories (Backend & API, Bases de données & ORM, Frontend & Mobile, Outils & Environnement).
- `/projects` — **Projets** : Sélection détaillée de 9 projets Backend et Full-Stack avec architecture, fonctionnalités clés, démos en ligne et liens vers les 34+ dépôts GitHub.
- `/contact` — **Contact** : Formulaire de contact, coordonnées directes (Email, Téléphone, WhatsApp, GitHub, LinkedIn) et téléchargement du CV PDF.
